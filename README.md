# configparse

A Haskell parser-combinator project with parsers for JSON and a subset of YAML,
built to help me learn the language. *Not intended for use.*

## Status

JSON parser is complete with an entrypoint in `Main.hs`. YAML parser is
in-progress.

## AI Usage

See CLAUDE.md for workflow details. I decided to undertake this project after
reading Hutton's *Programming in Haskell* to consolidate what I'd learned.
